Proyecto Integrador 2 Gestion de reserva de asientos de cine con matrices

Integrantes:

-Gadi Jeani Del Carmen Memije
-Roberto Adan Patino Rayo

Descripcion:

Administraremos las reservas de asientos de un cine con un menu interactivo en el cual los usuarios podran solicitar asientos y verificar su disponibilidad usando las matrices para manejar los asientos de forma bidimensional para identificar las reservaciones disponibles u ocupados.

Tecnologias Utilizadas:

-Lenguaje: C#
-Entorno: .NET Console Application
-Control de versiones: Git & GitHub

Instrucciones de Ejecucion:

-Clonar el repositorio git clone https://github.com/Roberto8322/Proyecto-Integrador-2-cine.git
-Abrir la solucion .sln en Visual Studio dentro de la carpeta Codigo
-Presionar F5 o el boton Iniciar para ejecutar la aplicacion de consola
